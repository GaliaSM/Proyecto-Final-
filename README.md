# 🐍 PROYECTO FINAL DESCRIPCION GENERAL

Este proyecto forma parte del Proyecto Final del curso. El objetivo es realizar un EDA completo y un dashboard operativo utilizando dos conjuntos de datos procedentes de fuentes diferentes, cumpliendo los requisitos mínimos establecidos.
El proyecto incluye:

     Limpieza y transformación profunda de los datos
     Análisis descriptivo
     Análisis estadístico
     Visualización de datos
     Dashboard Opertaivo
     Informes explicativos

## 🎯 Objetivo del Proyecto

Integrar dos datasets de fuentes distintas

      Construir un dataset final con más de 50.000 filas y 20 columnas
      Aplicar técnicas de limpieza, transformación y creación de nuevas variables
      Realizar análisis descriptivo y estadístico
      Crear un dashboard que aporte valor al análisis
